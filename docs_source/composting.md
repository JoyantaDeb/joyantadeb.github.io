# \# Feasibility Study of Short Time Aerobic Composting Using Vegetable Peels

# 

# \*\*Type:\*\* B.Tech Project-II Final Thesis Report (CE-4291)

# \*\*Institution:\*\* Department of Civil Engineering, IIEST Shibpur

# \*\*Supervisors:\*\* Prof. Debabrata Mazumder, Prof. Chanchal Majumdar

# 

# \## Summary

# 

# This project investigates accelerated aerobic composting of vegetable peels using structural pit reactors, evaluating decomposition efficiency across a compressed 7 to 14 day timeline. Key parameters monitored include total organic carbon (via Chemical Oxygen Demand), nitrogen content (via Total Kjeldahl Nitrogen), temperature variation, and moisture balance, providing a basis for assessing the feasibility of rapid composting methods for organic waste management.
