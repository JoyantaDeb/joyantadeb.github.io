# Feasibility Study of Short Time Aerobic Composting Using Vegetable Peels

* **Type:** B. Tech Project-II Final Thesis Report (CE-4291)
* **Institution:** Department of Civil Engineering, IIEST Shibpur
* **Advisors:** Prof. Debabrata Mazumder, Prof. Chanchal Majumdar
* **PDF Reference:** [Download Full Project Thesis](Feasibility%20analysis%20of%20short%20time%20aerobic%20composting%20using%20vegetables%20peels.pdf)

### Research Summary
Investigates accelerated structural pit reactors evaluating optimal organic decomposition metrics across a compressed 7-to-14-day timeline. Tracked indicators include total organic carbon metrics via chemical oxygen demand (COD), dynamic nitrogen metrics via Total Kjeldahl Nitrogen (TKN), temperature fluctuations, and moisture balance monitoring.
